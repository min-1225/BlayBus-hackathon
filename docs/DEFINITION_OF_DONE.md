# DEFINITION OF DONE

## Feature Done

각 기능은 아래를 만족해야 `Done`입니다.

```text
[ ] 요구사항 구현
[ ] Build 성공
[ ] 기본 테스트 완료
[ ] Error 처리
[ ] Contract 준수
[ ] 하드코딩된 환경 URL 없음
[ ] PR 작성
[ ] Reviewer가 실행 방법 이해 가능
```

---
